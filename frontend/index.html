    Настройки ИИ

    Модели используются раздельно для двух разных по сложности задач: разбор простых полей и сбор фактов (кнопка «Разобрать дело через ИИ») — задача проще, и составление связного текста по этим фактам (кнопка «Собрать обстоятельства дела») — задача сложнее, дешёвая модель здесь может ошибаться чаще. Цены — ориентировочные, актуальны на момент добавления модели в список; для точных расходов сверяйтесь с openrouter.ai/models.

    Прокси для запросов к OpenRouter

    Нужен, если сервер не может напрямую достучаться до OpenRouter (ошибка 403). Прокси временные — меняйте адрес прямо здесь: перезапускать сервер не нужно, новый адрес начинает работать сразу, со следующего запроса к ИИ.
    Загрузка…
    Формат: протокол://логин:пароль@адрес:порт. Протокол — http, https или socks5. После сохранения пароль на экране больше не показывается.

    Промпты полей для ИИ

    Инструкция для ИИ, что и как писать в конкретное составное поле (хронология обращений, обстоятельства получения травмы и т.п.). Пока промпт не задан — используется общий запасной вариант, функция всё равно работает, просто менее прицельно.

    Лог ИИ-запросов

    Для контроля качества разбора и расходов на токены. Полный текст фабулы и сканов в лог намеренно не попадает — только технические метрики и сводка результата.
